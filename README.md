# Flujo Profesional Completo en GitHub con Python

Proyecto colaborativo de la Sesión 8 de Actualización Tecnológica.

## Objetivo
Aplicar el flujo profesional completo de trabajo colaborativo en GitHub mediante un proyecto sencillo en Python.

## Flujo de trabajo
Solicitud de colaboración → Issue → Branch → Desarrollo → Commit → Push → Pull Request → Revisión → Corrección → Merge.

## Reglas de trabajo
- Cada estudiante trabajará solamente en el archivo correspondiente a su Issue.
- No modificar `main.py` salvo indicación expresa.
- Crear una rama con el formato `issue-N-descripcion-corta`.
- El mensaje del commit debe mencionar el número del Issue.
- El Pull Request debe dirigirse a `main`.
- En la descripción del PR utilizar `Closes #N` para vincularlo con el Issue.
- Si existen observaciones, corregir en la misma rama y actualizar el mismo Pull Request.

## Ejecución
Ejecutar:

```bash
python main.py
```

El programa permite ejecutar cada módulo de forma independiente desde un menú.
